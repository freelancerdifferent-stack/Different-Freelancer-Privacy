Privacy Policy for Image Resizer

Last updated: September 13, 2026

Image Resizer is developed by Different Freelancer Studio. This Privacy Policy explains how the application handles user data.

1. Image Processing

Images selected by the user are processed locally on the user's device. Image Resizer does not upload selected images to an external server or cloud service. The developer does not receive or store the contents of images processed by the app.

2. File Access

The application only accesses images and folders that the user explicitly selects through the Android system file picker. This access is used to resize images and save resulting files to the user-selected destination.

3. Accounts

Image Resizer does not require users to create an account or sign in. The developer does not maintain a server-side account database for Image Resizer.

4. Advertising and Google Mobile Ads

Image Resizer uses Google AdMob through the Google Mobile Ads SDK to display advertisements. According to Google's documentation for the Google Mobile Ads SDK, the SDK may automatically collect and share certain information for advertising, analytics, and fraud-prevention purposes, including the device's IP address, user interactions with the app and ads, diagnostic information, and device or account identifiers such as the Android advertising ID and app set ID where applicable.

Data transmitted by the Google Mobile Ads SDK is handled by Google under Google's own terms and privacy practices. For more information, see Google Privacy Policy and Google Mobile Ads SDK data disclosure information.

5. Consent and Privacy Choices

Image Resizer integrates Google's User Messaging Platform (UMP) SDK to support consent and privacy choices where required. Depending on the user's location and applicable law, Google may present a consent message before ads are requested. Where required, the app also provides access to advertising privacy choices.

6. Internet Access

The core image-resizing functionality is performed locally and can operate without uploading user images. Internet access is used by advertising and consent services provided through Google AdMob and the Google Mobile Ads SDK.

7. Data Sharing

The developer does not sell user images or personal information. Advertising-related information may be collected or shared by the Google Mobile Ads SDK as described above. Selected images themselves are not sent to Google AdMob by Image Resizer.

8. Data Retention and Deletion

Image Resizer does not maintain a remote database of user images or user accounts. Files created by the application remain on the user's device in the location chosen by the user and can be deleted by the user at any time. Advertising-related data collected by Google is subject to Google's retention and deletion practices.

9. Children's Privacy

Image Resizer does not knowingly collect user images or account information from children. Advertising services may process limited technical and advertising-related information as described in this policy and Google's documentation. The app's advertising configuration and store declarations will be maintained in accordance with the intended audience and applicable platform requirements.

10. Security

User-selected images are processed locally on the device. Google states that data collected by the Google Mobile Ads SDK is encrypted in transit using TLS.

11. Changes

This Privacy Policy may be updated if the application's features, advertising setup, SDKs, or data practices change. Updates will be published on this page.

12. Contact

For questions, contact the developer using the contact information provided on the application's Google Play Store listing.
