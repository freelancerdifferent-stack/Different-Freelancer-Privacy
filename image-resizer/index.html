Privacy Policy for Image Resizer

Last updated: September 13, 2026

Image Resizer is developed by Different Freelancer Studio. This Privacy Policy explains how the application handles user data.

1. Data Collection

Image Resizer does not collect, store, transmit, sell, or share personal information.

2. Image Processing

Images selected by the user are processed locally on the user's device. Image Resizer does not upload selected images to any external server or cloud service.

3. File Access

The application only accesses images and folders that the user explicitly selects through the Android system file picker. Access is used solely to resize images and save resulting files to the user-selected destination.

4. Internet and Accounts

The core image resizing functionality works offline. Image Resizer does not require users to create an account or sign in.

5. Analytics and Advertising

Image Resizer does not currently use third-party analytics, advertising SDKs, tracking technologies, or behavioral profiling.

6. Data Sharing

Because Image Resizer does not collect personal data, it does not share personal data with third parties.

7. Data Retention and Deletion

Image Resizer does not maintain a remote database of user information or uploaded images. Files created by the application remain on the user's device in the location chosen by the user and can be deleted by the user at any time.

8. Children's Privacy

Image Resizer does not knowingly collect personal information from children or other users.

9. Security

Image processing is performed locally on the device, reducing exposure of user images to external services.

10. Changes

This Privacy Policy may be updated if the application's features or data practices change. Updates will be published on this page.

11. Contact

For questions, contact the developer using the contact information provided on the application's Google Play Store listing.
