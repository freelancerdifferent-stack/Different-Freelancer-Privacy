Delete Account & Data - Image Resizer

Image Resizer does not create or maintain user accounts.

No account deletion request is required because the application does not provide account registration or login and does not maintain a remote user account database.

Deleting app data

Images created by Image Resizer are stored locally in the destination selected by the user. Users can delete those files at any time using their device's file manager or gallery application.

To remove local application settings or cached data, users can clear Image Resizer's storage from Android Settings or uninstall the application.

Server-side data

Image Resizer does not upload selected images or maintain server-side copies of the user's images or personal account data. Therefore, there is no Image Resizer server-side account data to request for deletion.
